[도메인 맥락]
나는 글로벌 문서 대행(번역·공증·아포스티유) 분야 콘텐츠 작성 1개월 차이고,
'한결 글로벌문서 솔루션 센터' 블로그를 6개월 안에 자산으로 만들려 합니다.
협력 업체가 처리 완료한 케이스 자료(고객 카톡 대화 + 마스킹된 완성 서류 PDF)를
받아, 네이버 블로그용 정보글 기반 후기글 1편으로 변환하는 작업을 반복합니다.

[네 동작 분석]
1. 분해: 자료에서 5개(의뢰 업무·문의 배경·문제 발생 지점·소요 기간·
   특이사항 및 완성 서류 구성) + 직접 조사해 붙이는 1개(국가별 주의사항)
2. 패턴: 동일 케이스 반복 축적 / 조사 정보의 업계 내 수렴 /
   업체 간 콘텐츠 평준화
3. 추상화: 검색 유입자가 자기 케이스의 필요 요건과 주의점을 얻어가고,
   맡겨도 되겠다고 판단하게 만드는 글 1편
4. 알고리즘: 자료 수신 → 의뢰 업무 확정 및 핵심 키워드 도출 →
   5개 축 분리 → 주의사항 조사 추가 → 정보 중심 후기글 작성 →
   태그 확장 → 검토

[출력 요구]
네이버 블로그 포스트 형식으로, 한국어로.
- 핵심 키워드는 '국가명 + 서류명 + 처리방식' 조합으로 제목에 반영
- 필요 요건과 주의사항은 본문에서 시각적으로 구분해 강조
- 국가별 요구조건은 변동되므로 확인 시점 표기
- 특이사항은 개인 식별이 되지 않도록 일반화해 서술

[검증 기준]
동종업계 경력자가 "실제 케이스를 처리해본 사람이 쓴 글"이라고 판단할 것.
해당 키워드로 검색해 들어온 사람이 추가 검색 없이 준비물과
주의점을 파악할 수 있을 것.
