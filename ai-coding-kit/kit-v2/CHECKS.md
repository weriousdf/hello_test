# CHECKS — 기계가 잴 수 없어 사람이 눈으로 판정하는 것만

**`결과` 칸은 사람만 채운다.** 모델이 채우면 이 표는 존재 이유를 잃는다.
게이트의 `manual_checks` 검사가 빈칸을 센다. **빈칸을 지워서 통과시키는 것은 계측기를 끄는 것이다.**

기계가 잴 수 있는 것은 여기 적지 말고 테스트로 만든다. 여기는 색·간격·읽히는 느낌·클릭감처럼
자동으로 판정할 수 없는 것의 자리다. **화면이 있는 프로젝트에서는 이 표가 주력이 된다.**

| 항목 | 무엇을 하면 무엇이 보이는가 | 결과 |
|---|---|---|

## 결과 칸에 적는 것

`PASS <날짜>` 또는 `FAIL <날짜> <무엇이 달랐는지>` 그리고 가능하면 `runs/<시각>/` 증거 경로.
`PASS` 만 적고 날짜가 없으면 언제 확인한 것인지 알 수 없다 — 코드가 바뀐 뒤의 PASS 인지 앞의 PASS 인지 구분되지 않는다.
