# ISSUES — 미해결 문제 원장

**모델이 적고, 사람만 닫는다.** 모델이 체크박스를 `[x]` 로 바꾸지 않는다.

## 형식

```
- [ ] ISS-<번호> | blocker|major|minor | <R-ID> | 처리:<N단계> | <증거 파일:줄 또는 증상> | <재현 명령 1줄>
```

**severity 를 낮추지 않는다.** 우회, 테스트 skip, 에러 무시, 하드코딩 중 하나라면 `blocker` 다.

**`처리:` 칸은 게이트를 통과시키지 않는다.** 열린 blocker 는 단계와 무관하게 게이트를 막는다.
이 칸은 사람이 '단계를 합칠까 / 지금 고칠까 / severity 를 다시 볼까' 를 판정할 근거다.

> 게이트가 이 칸을 존중하게 만들면 모든 blocker 를 먼 단계로 미루는 구멍이 열린다.
> v1 에서 ISS-002 가 5단계에서 발견됐지만 6단계 소관이었다. 사람이 **5·6단계를 한 덩어리로
> 마감**해서 풀었다. green 태그 하나를 잃었을 뿐 문제가 없었다. 편의를 위해 구멍을 만들 이유가 없다.
